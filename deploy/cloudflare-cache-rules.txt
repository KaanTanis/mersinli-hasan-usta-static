Cloudflare — agresif cache (deploy sonrası Purge Everything)
Site: mersinlihasanustatantuni.com

Origin (nginx / _headers) özeti:
  HTML / landing     → max-age=300, s-maxage=31536000  (edge 1 yıl, tarayıcı 5 dk)
  /assets/*, görseller → max-age=31536000, immutable

Ölçüm (Google Ads gtag) edge cache’ten etkilenmez; tarayıcıda çalışır.

═══════════════════════════════════════════════════════════════
DEPLOY RUTİNİ (zorunlu)
═══════════════════════════════════════════════════════════════

1) Dosyaları sunucuya yükle + nginx reload (conf değiştiyse)
2) Cloudflare → Caching → Configuration → Purge Cache → Purge Everything
3) curl ile doğrula (aşağıda)

Purge yapmadan deploy edersen ziyaretçiler edge’de eski HTML görebilir.

═══════════════════════════════════════════════════════════════
PANEL: Cache Rules (önerilen — 2 kural)
═══════════════════════════════════════════════════════════════

Dashboard → domain → Caching → Cache Rules

───────────────────────────────────────────────────────────────
KURAL 1 — Statik site: hepsi cache’lenebilir
───────────────────────────────────────────────────────────────

Rule name: Cache all static site

When incoming requests match → Custom filter expression:

  (http.host eq "www.mersinlihasanustatantuni.com" or http.host eq "mersinlihasanustatantuni.com")

Then:
  Cache eligibility     → Eligible for cache
  Edge TTL              → Respect origin Cache-Control (s-maxage / max-age)
  Browser TTL           → Respect origin
  Cache key             → Ignore query string   ← gclid/utm aynı HTML; hit oranı artar

Place at: First

Not: “Ignore query string” yalnızca cache anahtarı içindir; URL’deki gclid tarayıcıda kalır, Ads attribution bozulmaz.

───────────────────────────────────────────────────────────────
KURAL 2 (opsiyonel) — Origin 5xx / hata kısa TTL
───────────────────────────────────────────────────────────────

Çoğu planda gerekmez. Cloudflare zaten hata cevaplarını uzun cache’lemez.
